# Simulador rKA + CPAK

Versión lista para publicar en GitHub Pages.

## Archivo principal

- `index.html`: versión móvil robusta para iPhone/Safari.
- `simulador_v9_3_mobile.html`: versión HTML móvil previa, con más elementos.
- `simulador_v9_2_completo.html`: versión completa revisada.
- `rKA_CPAK_simulador_movil_excel.xlsx`: alternativa Excel/Numbers.

## Cómo publicarlo en GitHub Pages

1. Crear un repositorio nuevo en GitHub, por ejemplo:
   `rka-cpak-simulador`

2. Subir estos archivos al repositorio, manteniendo `index.html` en la raíz.

3. Ir a:
   `Settings` → `Pages`

4. En `Build and deployment` elegir:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`

5. Guardar.

6. Esperar 1–3 minutos. La página quedará disponible en una URL tipo:
   `https://TU-USUARIO.github.io/rka-cpak-simulador/`
